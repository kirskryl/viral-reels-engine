# Разобранные вирусные примеры (формулы, которые можно копировать)

Реальные ролики из базы, разложенные на «скелет». Бери формулу (последовательность ходов), а не
содержание — и подставляй тему + **нишу пользователя**. Ниша примеров не является дефолтом скилла.

---

### 12M — Провокация (Тип 1)
**Хук:** «Неэтичные способы заработка».
**Ходы:** бытовой крупный план (ест в кафе) → дерзкий тезис спокойным тоном → пауза + хитрый взгляд
→ цепочка риторических вопросов «а чё они сделают? пожалуются родителям?» → улыбка, обрыв.
**Почему сработало:** табу + деланое спокойствие + обрыв на вопросе = шквал комментариев-споров.
**Формула:** `[табу-тезис] → [пауза/взгляд] → [риторический вопрос] → [обрыв]`

---

### 11M — Мысленный эксперимент (Тип 2)
**Хук:** «Вы в курсе, что ваш мозг знает, каково это лизать всё что угодно?»
**Ходы:** странное обещание → инструкция «оглянись, выбери предмет, представь» → зритель
выполняет действие → «и ты почувствуешь это» → смех «это просто безумие».
**Почему сработало:** зритель физически вовлечён → досматривает и комментирует свой опыт.
**Формула:** `[обещание странной способности] → [инструкция действия] → [зритель пробует] → [вау-точка]`

---

### 10M — Чек-лист пользы (Тип 3)
**Хук:** «Гормоны, благодаря которым ты чувствуешь себя хорошо. И как их получить».
**Ходы:** заголовок-обещание → 4 блока (эндорфин/серотонин/окситоцин/дофамин) → под каждым список
способов, всё крупным текстом → финал «управляй и будь счастлив».
**Почему сработало:** концентрат пользы, который хочется сохранить и пересмотреть.
**Формула:** `[обещание пользы] → [N блоков по пунктам, текст на экране] → [призыв сохранить]`

---

### 8M — POV-скетч с клиффхэнгером (Тип 5)
**Хук:** «Блин, трэш! За мной 20 минут едет какой-то чувак».
**Ходы:** тревожная завязка (преследование) с таймкодами → диалог-знакомство → поворот (он замечает
отсутствие кольца) → согласие на свидание → «Остановились бы? Продолжение в профиле».
**Почему сработало:** мини-история + интрига + переход в профиль за развязкой.
**Формула:** `[интригующая завязка] → [нарастание] → [поворот] → [клиффхэнгер + профиль]`

---

### 5M — Исповедь (Тип 4)
**Хук:** «Какие выводы я сделала после двух своих браков?»
**Ходы:** вопрос-признание → история №1 (брак в 20, ребёнок) → история №2 (Бали, сильная любовь) →
главный инсайт «брак не обязан быть раз и навсегда» → обобщение для зрителя.
**Почему сработало:** уязвимость + сильный переосмысляющий вывод = репост «в точку».
**Формула:** `[личный вопрос] → [2 коротких истории] → [инсайт] → [обобщение для зрителя]`

---

### 3M — Разбор через «теорию» (Тип 6)
**Хук:** «Вот на этом фото видно всё про их отношения».
**Ходы:** обещание тайны + «досмотрите до конца» → ввод «Green Line Theory» → применение к
известной паре (наклон тел) → вывод «мужчина любит чуть больше».
**Почему сработало:** авторитет «теории» + любопытство на знакомых лицах.
**Формула:** `[обещание тайны] → [ввод фреймворка] → [применение к примеру] → [принцип-вывод]`

---

### 3M — Список-доказательство (Тип 7)
**Хук:** «Вот этой девушке изменил муж» (далее череда звёзд).
**Ходы:** быстрый ряд имён/фото (Дженнер, Бейонсе, Диана…) → нарастание → переход на говорящую
голову → главный тезис «женщина не виновата» → мостик к пользе.
**Почему сработало:** социальное доказательство + накопительный эффект ряда.
**Формула:** `[первый пример-крючок] → [нарастающий ряд] → [резкий вывод на камеру]`

---

### 3M — Метафора-инсайт (Тип 8)
**Хук:** «Почему март не заканчивается?»
**Ходы:** атмосферный кадр + смена надписей (не знаю → подумай → понял) → раскрытие: март = метафора
застоя → «закончится, когда сам начнёшь двигаться» (в описании).
**Почему сработало:** ёмкая метафора, в которой каждый узнаёт себя.
**Формула:** `[загадочный вопрос] → [минимализм кадра/надписей] → [метафора-разгадка]`

---

### 2M — Жёсткая правда (Тип 9)
**Хук:** «Вы не готовы к этой правде, но…»
**Ходы:** предупреждение «будет больно» → 4 конфронтационные правды (секс/деньги/цели/окружение),
каждая с текстом и видеоиллюстрацией → «с каким пунктом согласны?».
**Почему сработало:** провокация на самоидентификацию → споры в комментариях.
**Формула:** `[предупреждение] → [N жёстких правд по пунктам] → [спорный вопрос в коммент]`

---

### 3M — Сравнение/двойной экран (Тип 11)
**Хук:** «Сохрани: как делать рекламу правильно после нового закона».
**Ходы:** экран пополам (реклама/не реклама) → 5 пар сцен с подписями → мгновенно считываемая разница
→ «сохраняй примеры».
**Почему сработало:** прикладная польза в наглядном формате → сохранения.
**Формула:** `[обещание сохранить] → [5 пар «так/не так»] → [призыв сохранить]`
